How it works

Your key never leaves the proxy. Clients only hold revocable virtual keys.

You keep your provider account and your own key. Spend Brake stores it encrypted, forwards each request with it, and hands your apps and agents sb_live_… keys you can cap, scope and kill.

  1. Authenticate

    The virtual key is checked (cached 5 s) along with its environment, agent and session.

  2. Price

    SKU from the path and field mask, worst case in micro-dollars, from price files that cite their source.

  3. Reserve

    One Lua call on Valkey: kill switch, loop breaker, and a reservation against every cap at once.

  4. Forward

    The real key is decrypted locally and never logged. Responses stream through; nothing is cached.

  5. Settle

    The actual cost replaces the reservation and a usage event lands in the ledger, in the background.

app / agent → proxy → provider, then Valkey → worker → Postgres ledger → alerts → webhooks / email. Valkey down means fail closed (503) unless a key opts into a small fail-open allowance.

What you get

Caps that hold, and everything around them.

Hard caps at every scope

Per org, key, SKU, environment, agent and agent session; per day and per month. All checked atomically, so parallel requests cannot slip past together.

Priced per SKU, in real time

Google Maps Platform Places, Geocoding and Routes priced per field mask; Twilio settled at its final price. A daily check watches provider price pages for drift.

Kill switch

One call, link or button stops a key, a provider, a session or the whole org immediately. Alerts carry signed Kill, Raise and Mute links so you can act from your phone.

Loop detection

A circuit trips when a key repeats identical requests, or a session pumps calls, past your rule. The caller gets 429 loop_detected with a retry time, and you get an alert.

Budget alerts with actions

Signed webhooks with Slack, Discord and Teams presets or raw JSON, plus email. Thresholds, kills, loops and price changes, each with one-click actions.

Telemetry for each org

Your own Prometheus endpoint at GET /v1/metrics: requests by outcome, cost, refunds, latency histograms and live budget. OpenTelemetry export sends every call as a span to your collector, joined to the caller's trace.

The brake CLI

brake init sets up an org, stores the provider key and prints the exact Google Cloud steps to restrict it to the proxy. brake session runs any agent inside its own budget.

Built to stay inside provider terms

Bring your own key, always. Responses are never cached to cut billing. Only request metadata is stored, never bodies or query strings. Every request reaches the provider with your key.

Migration estimate

For AI agents

Give every agent run a budget it cannot talk its way out of.

Run any agent or script inside a session with its own cap. When the money runs out, the agent gets one line telling it to stop and ask you, not a quietly growing bill.

  • Session keys that can spend at most what you say, count against the agent's daily budget and the parent key's caps, and are revoked when the agent exits.
  • Capped calls from inside the agent: brake maps geocode, brake maps search or brake call <provider> <method> <path>, each printing the cost.
  • Clear exit codes (3 for a cap, 4 for the loop breaker) with one line the agent can act on.
  • Per-session loop rules and, on the Agents plan, session analytics and custom loop rules.

Compared with Google's own controls

Budgets alert. Quotas count requests. Spend Brake stops dollars.

Keep Google's budgets and quotas on as a backstop. Spend Brake is the part that acts before the money is spent.

Self-hosting

Run it on your own host in five minutes.

One Docker Compose file starts the proxy, admin API, notifier, dashboard, worker, Valkey and Postgres. An HTTPS overlay adds Caddy with automatic certificates; proxy replicas and Valkey Cluster are covered when you outgrow one box.

  • Nothing phones home. Licenses are Ed25519-signed files verified offline. A self-hosted install sends no data to Spend Brake.
  • Backups and upgrades are scripted. For now you build the images and the CLI from source; published images and an npm package are coming.
  • The same CLI works against your install: brake init --api-url … --proxy-url …

Read the self-hosting guide

quickstart
$ git clone https://github.com/KIvanow/spend-brake && cd spend-brake
$ cp infra/.env.example infra/.env   # fill in the secrets
$ docker compose -f infra/docker-compose.yml up -d --build --wait

$ pnpm install && pnpm --filter @spend-brake/cli build
$ node apps/cli/dist/brake.cjs init --api-url http://localhost:8081 \
    --proxy-url http://localhost:8080 --org acme --day-cap 5 --month-cap 50
Org acme is ready. An admin token is saved to ~/.config/brake/config.json.

Caps only hold if the proxy is the only path to spend.

Restrict each provider key to the proxy's outbound IP addresses and the APIs you use; brake init prints the exact steps. Keep the provider's own budgets and quotas on as a backstop. Overshoot is bounded by one request's worst case, and your provider's bill remains the authoritative record of what you spent.
